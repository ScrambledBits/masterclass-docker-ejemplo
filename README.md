# Bootcamperu Landing Page

Esta es la página de inicio oficial de Bootcamperu, un espacio diseñado para transformar apasionados de la tecnología en desarrolladores expertos.

## Características

- **Diseño Dark Mode:** Estética moderna y elegante.
- **Vibe de Código:** Interfaz inspirada en terminales de comandos para una experiencia auténtica.
- **Responsive:** Adaptable a cualquier dispositivo.
- **Construido con:** React 19 + Vite.

## Desarrollo

Para iniciar el servidor de desarrollo:

```bash
npm run dev
```

Para construir la versión de producción:

```bash
npm run build
```

## Estructura del Proyecto

- `src/App.jsx`: Componente principal con la estructura de la landing page.
- `src/App.css`: Estilos específicos de los componentes.
- `src/index.css`: Estilos globales y variables de color (Theme).
